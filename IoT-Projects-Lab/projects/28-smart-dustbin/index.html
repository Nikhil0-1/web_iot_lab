Hardware Setup — Project 28: Smart Dustbin

Components: NodeMCU ESP8266, HC-SR04 Ultrasonic Sonar, TCRT5000 IR Proximity Module, TowerPro SG90 Servo.

Connections:

  • HC-SR04 Trig → D1 (GPIO 5)
  • HC-SR04 Echo → 1kΩ/2kΩ divider → D2 (GPIO 4)
  • SG90 Servo PWM → D5 (GPIO 14)
  • IR Proximity Sensor DO → D6 (GPIO 12)
  • Servo Power → External 5V Regulated supply

Technical Distinction: The IR proximity module triggers the touchless hand wave lid opening, while the ultrasonic sensor measures the internal waste volume.
