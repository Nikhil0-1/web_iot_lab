# Project 27 · RFID Door Access

## Overview
A secure portal access controller incorporating a digital keypad, solenoid electronic bolt driver, and brute-force lockout rate limiting.

## Features
- Interactive 3D door panel with retractable solenoid bolt animation.
- Digital 12-key matrix keypad with audible tones and brute-force rate limiting (3 strikes lockout).
- Auto-relocking fail-safe logic (auto-locks after 4 seconds).
- REST API server on ESP8266 supporting secure unlock commands.
