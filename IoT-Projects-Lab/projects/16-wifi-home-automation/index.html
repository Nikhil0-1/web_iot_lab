Setup — Project 16: Wi-Fi Home Automation

Components: NodeMCU ESP8266, 4-Channel 5V Optocoupled Relay Board, External 5V Power Supply.

Relay Pin Connections:

  • Relay 1 (Living Light) → D1 (GPIO 5)
  • Relay 2 (Fan) → D2 (GPIO 4)
  • Relay 3 (AC) → D5 (GPIO 14)
  • Relay 4 (Kitchen) → D6 (GPIO 12)
  • Relay VCC → 5V External, Relay GND → NodeMCU GND

Firmware: Flash firmware/wifi_home_automation.ino via Arduino IDE.

Safety: Relays are active-LOW. All outputs are initialized HIGH (Relay OFF) on microcontroller boot to prevent inadvertent appliance turn-on.
