Setup — Project 20: Servo Motor Web Control

Components: NodeMCU ESP8266, SG90 Micro Servo or MG996R Metal Gear Servo, External 5V 2A DC Power Supply.

Wiring:

  • Servo PWM Signal (Orange/Yellow) → D5 (GPIO 14)
  • Servo Power VCC (Red) → External 5V DC supply (+)
  • Servo Ground (Brown/Black) → External Supply (-) and ESP8266 GND (Common Ground)

CRITICAL POWER WARNING: Never draw 5V servo motor current from the ESP8266 onboard 3.3V voltage regulator! Servo stall currents (500mA–2.5A) cause immediate brownout crashes or burnt linear regulators.

Firmware: Flash firmware/servo_control.ino via Arduino IDE.
