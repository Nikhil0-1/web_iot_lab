# Project 33 · Battery Voltage Monitor

## Overview
A precision DC battery pack health telemetry and discharge monitoring station with multi-chemistry curve modeling (Lead-Acid, Li-Ion, LiFePO4) and low-voltage protection warnings.

## Features
- Animated battery cylindrical cell graphic with dynamic fluid level and voltage overlay.
- Chemistry-specific discharge thresholds with raw ADC telemetry.
- Real-time voltage history canvas trend graph.
- Calibration endpoint for voltage reference and precision divider adjustments.
