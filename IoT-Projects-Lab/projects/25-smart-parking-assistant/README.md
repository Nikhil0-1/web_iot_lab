# Project 25 · Smart Parking Assistant

## Overview
An automated parking management system using an ultrasonic distance sensor for bay occupancy detection, dual LED status indicators, and an SG90 micro-servo barrier gate.

## Features
- Dynamic top-down visual parking lot with 4 monitored bays.
- Ultrasonic pulse sonar reading with real-time distance gauge.
- Automatic servo barrier arm actuation on entry/exit.
- REST API server on ESP8266 providing live bay occupancy and barrier control.
