Hardware Setup — Project 26: RFID Attendance

Components: NodeMCU ESP8266, MFRC522 13.56MHz Reader, 5V Active Buzzer, NPN 2N2222.

SPI Bus Pinout:

  • VCC → 3.3V ONLY (Do NOT connect 5V to RC522!)
  • RST → D3 (GPIO 0)
  • GND → GND Common
  • MISO → D6 (GPIO 12)
  • MOSI → D7 (GPIO 13)
  • SCK → D5 (GPIO 14)
  • SDA (SS) → D8 (GPIO 15)
  • Buzzer Chime → D1 (GPIO 5) via 2N2222 transistor

Firmware: Flash firmware/rfid_attendance.ino with MFRC522 library.
