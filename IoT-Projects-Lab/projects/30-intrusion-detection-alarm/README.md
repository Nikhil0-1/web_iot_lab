# Project 30 · Intrusion Detection Alarm

## Overview
A multi-zone intrusion perimeter defense system utilizing an HC-SR501 passive infrared (PIR) motion sensor, an acoustic piezo siren, and arm/disarm state telemetry.

## Features
- Dynamic security blueprint canvas with animated intruder target and detection zone arcs.
- Arm and Disarm control with active status telemetry.
- Audio synthesis siren alert matching armed breach conditions.
- Native ESP8266 REST API supporting live motion telemetry and arm/disarm command dispatch.
