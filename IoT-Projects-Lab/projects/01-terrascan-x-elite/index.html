Hardware Setup & Wiring: TERRASCAN X ELITE

Required Components: ESP8266 NodeMCU, HC-SR04 Ultrasonic Distance Sensor, 1kΩ and 2kΩ resistors (for 5V Echo to 3.3V GPIO level shifting), Breadboard & Jumper Wires.

Pinout Wiring Table

HC-SR04 Pin ESP8266 Pin Description
VCC VIN (5V) Sensor 5V power supply
GND GND Common ground
TRIG D1 (GPIO5) 10µs ultrasonic trigger pulse
ECHO D2 (GPIO4) via divider Echo return pulse (Level-shifted to 3.3V)

Flashing Firmware:

  1. Open firmware/terrascan_x_elite.ino in Arduino IDE.
  2. Install ArduinoJson and ESP8266 board support via Board Manager.
  3. Set your Wi-Fi SSID and password in the firmware header.
  4. Upload to ESP8266 and open the Serial Monitor (115200 baud) to find the device IP.
