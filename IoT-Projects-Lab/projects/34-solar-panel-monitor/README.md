# Project 34 · Solar Panel Monitor

## Overview
A real-time photovoltaic power generation tracking dashboard measuring bus voltage, shunt current, and cumulative watt-hours using the Texas Instruments INA219 I²C sensor and NodeMCU ESP8266.

## Features
- Dynamic sun and solar panel canvas rendering daylight angles and photon ray projections.
- High-side current and voltage measurements with daily yield accumulator (Wh).
- Technical notes concerning INA219 26V DC bus ceiling.
- Native ESP8266 REST API providing solar yield telemetry.
