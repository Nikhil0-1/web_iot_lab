DS18B20 & ESP8266 Hardware Setup

1. Wiring Connections:

  • Pin 1 (GND): Connect to ESP8266 GND
  • Pin 2 (Data): Connect to ESP8266 Pin D4 (GPIO2)
  • Pin 3 (VDD): Connect to ESP8266 3.3V
  • Pull-up Resistor: Connect a 4.7kΩ resistor between Pin 2 (Data) and Pin 3 (3.3V). The OneWire bus requires this pull-up resistor to maintain line state during idle periods.

2. Firmware Upload:

  1. Open firmware/digital_thermometer.ino in Arduino IDE.
  2. Install the OneWire and DallasTemperature libraries via Library Manager.
  3. Configure your Wi-Fi SSID and Password in the sketch.
  4. Select board NodeMCU 1.0 (ESP-12E Module) and click Upload.
