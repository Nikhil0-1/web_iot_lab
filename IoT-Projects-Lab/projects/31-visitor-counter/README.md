# Project 31 · Visitor Counter

## Overview
A bi-directional optical doorway transit monitoring system employing dual infrared break-beam sensors with finite-state directional decoding and real-time facility occupancy estimation.

## Features
- Interactive animated portal canvas rendering visitor transitions with sequential beam tripping.
- Debounce window and directional state machine (A &rarr; B = In, B &rarr; A = Out).
- In, Out, and net occupancy counters with manual reset.
- Native ESP8266 REST API providing cumulative traffic statistics.
