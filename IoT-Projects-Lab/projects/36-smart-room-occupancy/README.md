# Project 36 · Smart Room Occupancy

## Overview
A smart building human occupancy and dwell monitoring system powered by the Hi-Link HLK-LD2410 24GHz FMCW millimeter-wave radar sensor, detecting stationary human micro-motions (breathing) and active movement.

## Features
- Real-time room floorplan canvas with sweeping mmWave radar fan beam and target position tracking.
- Continuous dwell timer accurately counting occupancy duration without false PIR sleep cutoffs.
- Technical distinction between continuous micro-presence sensing vs directional transit counting.
- Native ESP8266 REST API providing target distance, dwell time, and motion classification.
