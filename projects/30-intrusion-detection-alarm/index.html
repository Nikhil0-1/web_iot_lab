Hardware Setup — Project 30: Intrusion Detection Alarm

Components: NodeMCU ESP8266, HC-SR501 Passive Infrared Sensor, Piezo Alarm Siren, Status LED.

Wiring:

  • HC-SR501 VCC → 5V External Power
  • HC-SR501 GND → Common GND
  • HC-SR501 OUT → NodeMCU D5 (GPIO 14) [Outputs 3.3V TTL signal]
  • Piezo Siren → NodeMCU D1 (GPIO 5) via 2N2222 transistor buffer
  • Arm/Disarm LED → NodeMCU D2 (GPIO 4) via 220Ω resistor

Firmware: Flash firmware/intrusion_alarm.ino.
