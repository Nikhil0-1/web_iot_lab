Hardware Setup — Project 29: Fire & Smoke Alert

Components: NodeMCU ESP8266, MQ-2 Combustible Gas/Smoke Sensor, Optical Flame Sensor, Active Piezo Buzzer, Red Alert LED.

Wiring Assignments:

  • MQ-2 VCC → 5V External (Heater coil draws 150mA continuous!)
  • MQ-2 AO → NodeMCU A0 (via 10k/20k voltage divider)
  • Flame Sensor DO → D1 (GPIO 5)
  • Piezo Buzzer → D6 (GPIO 12) via 2N2222 transistor
  • Red Alert LED → D7 (GPIO 13) via 220Ω resistor

Heater Burn-in: New MQ-2 sensors require a 24-hour thermal preheat cycle before baseline resistance R0 stabilizes.
