# Project 29 · Fire & Smoke Alert

## Overview
An industrial safety environmental hazard monitor using an MQ-2 smoke transducer, optical phototransistor flame sensor, active piezo siren, and customizable alert threshold.

## Features
- Dynamic smoke particle plume canvas simulation with Web Audio frequency-modulated siren.
- Normal, Warning, and Emergency Alarm states with prominent banner alerts.
- Configurable PPM alert threshold slider.
- Clear educational disclaimer noting non-certified consumer sensor constraints.
