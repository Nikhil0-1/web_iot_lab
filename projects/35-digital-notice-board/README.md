# Project 35 · Digital Notice Board

## Overview
A wireless digital announcement terminal pairing an SSD1306 0.96" 128x64 I²C monochrome OLED screen with a browser-based marquee dispatch console.

## Features
- Pixel-accurate 128x64 monochrome OLED canvas emulation with CRT scanline rasterization.
- Editable message broadcaster with configurable font sizes and marquee scroll speeds.
- Preset broadcast library for quick facility announcements.
- ESP8266 REST API command receiver updating physical display in real-time.
