Setup — Project 17: Fan Speed Controller

Components: NodeMCU ESP8266, Logic-Level N-Channel MOSFET module (IRLZ44N or IRF520), 12V DC brushless fan, 12V external power supply.

Wiring:

  • MOSFET SIG (Gate) → D1 (GPIO 5)
  • MOSFET VCC/GND logic → 3.3V and GND
  • Fan (+) → 12V Supply (+)
  • Fan (-) → MOSFET Drain (VIN-)
  • 12V Supply (-) → Common GND

Firmware: Flash firmware/fan_speed_controller.ino. Uses 1 kHz hardware PWM timer.

Caution: Never attempt to control high-voltage AC ceiling fans directly using a simple DC MOSFET!
