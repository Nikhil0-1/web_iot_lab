# Project 26 · RFID Attendance System

## Overview
A contactless institutional attendance verification terminal based on the MFRC522 13.56MHz RFID reader and ESP8266 NodeMCU.

## Features
- Interactive RFID card-tap simulation with Web Audio chime.
- Real-time attendance registry with search, filtering, and live daily statistics.
- Instant CSV export of daily roll call logs.
- Native ESP8266 REST API emitting scanned card UIDs and timestamp metadata.
