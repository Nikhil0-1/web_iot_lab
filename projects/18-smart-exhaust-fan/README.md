# Project 18 — Smart Exhaust Fan

## Purpose
Automatically operate an exhaust fan based on temperature and humidity thresholds
measured by a DHT22 sensor.

## Hardware
- ESP8266 NodeMCU
- DHT22 (AM2302) temperature/humidity sensor
- N-Ch MOSFET or relay-based fan driver
- DC exhaust fan (appropriate voltage/current)

## Features
- Temperature and humidity display
- Auto/manual fan modes
- Configurable temperature and humidity thresholds
- Hysteresis to prevent rapid cycling
- Fan event history
- Environmental trend charts
