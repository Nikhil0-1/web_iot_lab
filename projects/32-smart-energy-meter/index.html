Hardware Setup — Project 32: Smart Energy Meter

Components: NodeMCU ESP8266, PZEM-004T v3.0 AC Power Transducer with 100A CT Split-Core Clamp.

Optoisolated TTL Connections:

  • PZEM 5V → 5V External Supply
  • PZEM GND → Common GND
  • PZEM TX → NodeMCU D5 (GPIO 14 / Software RX)
  • PZEM RX → NodeMCU D6 (GPIO 12 / Software TX via 1k/2k divider)

Safety Precaution: Galvanic isolation separates high-voltage AC from low-voltage microcontrollers. Never bypass optocouplers.
