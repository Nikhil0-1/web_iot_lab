Setup — Project 22: Stepper Motor Controller

Components: NodeMCU ESP8266, A4988 or DRV8825 Stepper Driver carrier, NEMA 17 Stepper Motor, 12V 2A External Power Supply, 100µF decoupling capacitor across VMOT/GND.

Wiring:

  • Driver STEP → D1 (GPIO 5)
  • Driver DIR → D2 (GPIO 4)
  • Driver ENABLE → D5 (GPIO 14) (Active LOW)
  • Driver VDD / GND → 3.3V and GND
  • Driver VMOT / GND → 12V Supply with 100µF capacitor
  • Driver 1A/1B/2A/2B → Stepper 4-wire phases

Firmware: Flash firmware/stepper_controller.ino. Uses hardware timer for non-blocking step generation.
