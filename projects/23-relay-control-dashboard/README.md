# Project 23 — Relay Control Dashboard

## Purpose
Independent control of 4-8 relay channels with configurable labels, timed auto-off
and full command history.

## Features
- Up to 8 relay channel cards
- Individual ON/OFF per channel
- All-on / all-off
- Configurable channel labels
- Auto-off timer per channel
- Command history
- Commanded vs confirmed hardware state indication
- Simulated connection loss scenario

## Safety
- Use relay NO contacts for all demonstration loads
- For mains-voltage circuits: proper isolation, enclosure, and qualified installation required
- Document all load specifications
- Implement safe boot defaults (relay off on power-up)
