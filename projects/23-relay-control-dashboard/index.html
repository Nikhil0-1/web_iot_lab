Setup — Project 23: Relay Control Dashboard

Components: NodeMCU ESP8266, 4-Channel 5V Optocoupled Relay Board, External 5V Power Supply.

Relay Pin Connections:

  • Relay 1 IN → D1 (GPIO 5)
  • Relay 2 IN → D2 (GPIO 4)
  • Relay 3 IN → D5 (GPIO 14)
  • Relay 4 IN → D6 (GPIO 12)
  • Relay JD-VCC / VCC → External 5V Power Supply
  • Relay GND → Common System GND

Firmware: Flash firmware/relay_dashboard.ino via Arduino IDE.

High-Voltage Safety: For any AC mains wiring (110V/230V), always use an insulated terminal enclosure, install a physical fuse, and maintain optocoupled isolation between the ESP8266 logic and mains lines.
