Hardware Setup — Project 36: Smart Room Occupancy

Components: NodeMCU ESP8266, Hi-Link HLK-LD2410 24GHz Human Presence Radar Sensor, 5V External Supply.

UART Serial Pinout:

  • LD2410 VCC → 5V External Power (Draws 80mA average)
  • LD2410 GND → Common GND
  • LD2410 TX → NodeMCU D7 (GPIO 13 / Software RX)
  • LD2410 RX → NodeMCU D8 (GPIO 15 / Software TX via 1k/2k divider)
  • LD2410 Out (GPIO High on target) → Optional D5 (GPIO 14)

Firmware: Flash firmware/room_occupancy.ino with SoftwareSerial.
