Setup — Project 19: Automatic Door Controller

Components: NodeMCU ESP8266, HC-SR04 Ultrasonic Distance Sensor, SG90 or MG996R Servo Motor, 5V 2A External Power Supply for Servo.

Wiring:

  • HC-SR04 Trig → D1 (GPIO 5)
  • HC-SR04 Echo → D2 (GPIO 4) via 1kΩ/2kΩ voltage divider
  • Servo PWM Signal → D5 (GPIO 14)
  • Servo VCC → External 5V Power Supply (NEVER from ESP8266 3.3V pin!)
  • Servo GND → Common System GND

Firmware: Flash firmware/automatic_door.ino via Arduino IDE.

Safety Note: This is an educational demonstration project. Real commercial automatic doors require safety light curtains, pressure-sensitive mats, and mechanical emergency egress releases.
