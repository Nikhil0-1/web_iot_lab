Setup — Project 21: DC Motor Control Panel

Components: NodeMCU ESP8266, TB6612FNG or L298N H-Bridge Driver module, 12V DC Gearmotor, 12V External Motor Supply.

Wiring:

  • Driver IN1 → D1 (GPIO 5)
  • Driver IN2 → D2 (GPIO 4)
  • Driver PWM (ENA) → D5 (GPIO 14)
  • Driver VM → 12V Motor Supply (+)
  • Driver GND → Common System GND
  • Motor Outputs → DC Motor Terminals

Firmware: Flash firmware/dc_motor_control.ino. Implements interlocked direction changes preventing shoot-through short circuits on the bridge.
