# Project 28 · Smart Dustbin

## Overview
A hygienic, automated touchless dustbin system combining an infrared proximity sensor for gesture-based lid actuation and an ultrasonic sonar sensor for internal volume fill-level telemetry.

## Features
- Animated mechanical lid with realistic servo opening/closing rotation.
- Visual internal waste fill column with capacity warning triggers (>85%).
- Distinction between IR proximity (hand wave trigger) and ultrasonic depth (bin volume).
- Native ESP8266 REST API providing fill percentage and lid control.
